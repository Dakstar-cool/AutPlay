# Импорт музыки по ссылке

На Android откройте импорт плейлиста или отправьте ссылку в AutPlay через «Поделиться». На настольном клиенте откройте «Импорт по ссылке» в разделе плейлистов подключённого аккаунта. Для переноса личных отметок выберите «Перенести любимые» до открытия ссылки.

Предпросмотр показывает заявленное и прочитанное число позиций, известные записи и доступное владельцу аудио. Если числа расходятся, пользователь может сохранить доступную часть. Обычный плейлист сохраняет порядок и повторы. У альбома сохраняются издание, номера дисков и дорожек. Отдельное подтверждение избранного создаёт личные отметки. История прослушиваний пополняется во время воспроизведения.

## Первый вход и Моя волна

После создания аккаунта на сервере Android и настольный клиент предлагают перенести любимые треки, затем выбрать исполнителей. Оба шага можно пропустить. Нажатие на исполнителя раскрывает до двух похожих под его рядом. Можно углубиться на три уровня или найти другого исполнителя через поиск. Выбор сохраняется на сервере для всего аккаунта.

Для стартовых рекомендаций AutPlay учитывает подтверждённые любимые из Яндекс Музыки и независимо идентифицированные записи AutPlay, явно сохранённые из предпросмотра SoundCloud. При переносе из Spotify начальный выбор можно сделать в собственном каталоге AutPlay. Ручной выбор даёт артисту вес 5, избранное — 4. Повторный импорт сохраняет тот же вес, а дальнейшие прослушивания постепенно снижают влияние стартового выбора.

## Сервер и доступ к источникам

API и CPU worker должны работать на одной версии приложения с миграциями Alembic до `0081_artist_onboarding` включительно. Примените миграции обычным процессом обновления AutPlay. Переменные ниже относятся к процессу API. Файлы ключей должны быть доступны для чтения только соответствующему серверному процессу.

| Источник | Что подключить |
|---|---|
| Яндекс Музыка | Для открытых альбомов и плейлистов достаточно ссылки. Для персонального адреса `/collection` предусмотрена переменная `AUTPLAY_IMPORT_YANDEX_TOKEN_DIR`. В этом каталоге файл с именем, равным UUID владельца AutPlay, содержит его OAuth-токен Яндекса. Для публичного плейлиста «Мне нравится» в режиме избранного сервер сверяет ID с доступным списком отметок. |
| Spotify | Задайте `AUTPLAY_IMPORT_SPOTIFY_CLIENT_ID`, `AUTPLAY_IMPORT_SPOTIFY_REDIRECT_URI` и `AUTPLAY_IMPORT_KEY_FILE`. Зарегистрируйте у Spotify тот же HTTPS-адрес с путём `/api/v1/collection-imports/spotify/callback`. Файл ключа содержит результат `Fernet.generate_key()`. Все экземпляры API используют один ключ. По умолчанию доступны собственные плейлисты и сохранённые треки. Для приложения, зарегистрированного в Development Mode, задайте `AUTPLAY_IMPORT_SPOTIFY_QUOTA_MODE=development`, чтобы допускать совместные плейлисты при успешной проверке доступа к составу у Spotify. Альбом по ссылке ищется по внешнему ID издания в каталоге AutPlay. |
| SoundCloud | Задайте `AUTPLAY_IMPORT_SOUNDCLOUD_APP_TOKEN_FILE` с действующим токеном приложения для чтения публичных метаданных. За обновление токена отвечает оператор приложения. Лайки треков и сетов показаны отдельно. Ссылка на понравившийся сет открывает собственный предпросмотр. Можно явно сохранить позиции, для которых у владельца уже есть независимо полученная запись AutPlay с доступным аудио. |

Spotify использует OAuth PKCE. После входа вернитесь в окно импорта и нажмите «Продолжить». Разрешение привязано к одному владельцу и одной операции. При подтверждении сервер повторно проверяет доступ и удаляет токен из предпросмотра. CPU worker удаляет неподтверждённые операции Spotify старше часа, SoundCloud старше суток и Яндекса старше недели. Временные страницы SoundCloud хранятся в памяти процесса API до двух минут между запросами. Сет, помеченный как альбом, можно сохранить как издание, когда оно независимо известно каталогу и совпадает весь треклист. Для нескольких процессов API постоянная привязка сеанса к одному экземпляру позволяет продолжать длинный предпросмотр SoundCloud с последней страницы.

## Контракт клиентов

Все операции под `/api/v1/collection-imports`, кроме обратного вызова OAuth, требуют сессию AutPlay. Владельца определяет сервер.

| Запрос | Результат |
|---|---|
| `POST /collection-imports` | Передайте `operation_id` (UUID), `url`, `favorites` и при необходимости `new_copy`. Для повтора запроса используйте тот же UUID. |
| `GET /collection-imports` | Последние 30 операций владельца. |
| `GET /collection-imports/{id}?offset=0` | Состояние, счётчики, редакция и до 50 позиций постоянного предпросмотра. Следующее смещение задаёт `next_offset`. |
| `POST /collection-imports/{id}/resume` | Прочитать следующую страницу, повторить доступ или продолжить после входа. При ответе 429 действует `Retry-After`. |
| `POST /collection-imports/{id}/confirm` | Передайте `revision` из предпросмотра. Для выбранных записей каталога из SoundCloud передайте также выданный сервером `selection_key`. Успешный ответ содержит `import_job_id` для разбора версий. |
| `POST /collection-imports/{id}/cancel` | Отменить неподтверждённый импорт и очистить предпросмотр. |

При неоднозначном совпадении выберите версию в существующем экране разбора импорта. На настольном клиенте номер серверного задания доступен в результате сохранения. Для альбома и избранного запрос аудио проходит через очередь разрешённого источника. В этой версии поддержан уже известный владельцу доступный для выбора кандидат Jamendo с подтверждённым ID записи. Для его обработки требуется настроенный работник получения аудио.
