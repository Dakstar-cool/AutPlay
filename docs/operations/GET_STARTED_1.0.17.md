# Начало работы с AutPlay 1.0.17

[Скачать выпуск](https://github.com/Dakstar-cool/AutPlay/releases/tag/v1.0.17).
В нём доступны Android APK, Mac Community DMG, архив образа сервера. Контрольные суммы приведены в описании.
Для локальной музыки аккаунт и сервер не нужны.

## Android

1. Скачайте `autplay-1.0.17-production.apk` на устройство с Android 8.0 или новее.
2. Откройте APK и разрешите установку этому источнику, если Android запросит разрешение.
3. Для обновления устанавливайте поверх текущей версии, сохраняя данные приложения.
   Если подпись не совпадает, остановитесь: не удаляйте приложение с важными локальными данными.
4. Откройте **«Моя музыка» → «Добавить локальный трек»**, выберите файл и включите его.

Версия приложения — `1.0.17`, код версии — `40`, пакет — `app.autplay`.
Используется тот же издательский ключ, что в подписанном выпуске 1.0.16.

## Mac Community

Нужен Mac с Apple Silicon (M1 или новее), целевая система — macOS 13+.
Нативные автоматические проверки выполняются на macOS 15 и 26; отдельной сборки для Intel нет.

1. Скачайте `autplay-1.0.17-macos-arm64.dmg`.
2. При необходимости проверьте файл командой:
   ```bash
   shasum -a 256 ~/Downloads/autplay-1.0.17-macos-arm64.dmg
   ```
   Сравните результат с SHA-256 в описании выпуска.
3. Откройте DMG и перенесите **AutPlay.app** в **«Программы»**. Запускайте приложение оттуда.
4. Community-сборка подписана собственным сертификатом проекта, без нотарификации Apple.
   Если первый запуск блокируется, после попытки запуска откройте
   **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
   Подтвердите только скачанное приложение. [Порядок действий Apple](https://support.apple.com/en-us/102445).
5. В библиотеке выберите **«Добавить музыку»**, затем файлы или папку.
   Приложение создаёт управляемые копии и сохраняет исходные файлы.

Для обновления завершите AutPlay и замените приложение в «Программах».
Данные библиотеки остаются отдельно от приложения. macOS может повторно запросить доступ
к существующим элементам Связки ключей; используйте явное повторное открытие аккаунтов
в приложении и системное подтверждение доступа.

Community-версия использует Keychain, но не Secure Enclave. Блокировка или отказ доступа
к Keychain не должны заменяться созданием новых ключей или удалением существующего аккаунта.
[Устройство защиты и ограничения](MACOS_COMMUNITY.md).

В Mac Community доступны локальная «Моя волна», пакеты рекомендаций подключённого аккаунта,
поиск в каталоге и перенос плейлистов. Комнаты доступны на Android. Слышимый звук, все сочетания кодеков/контейнеров, медиаклавиши,
сон/пробуждение и интерактивное обновление требуют дополнительной ручной проверки.

## Аккаунт и сервер

На Android создайте аккаунт с ID и паролем и сохраните файл восстановления отдельно.
Подключение к личному серверу позволяет войти на другом совместимом устройстве.
Для входа по ID и паролю сервер должен уже хранить документ этого аккаунта.

На Mac:

1. Откройте **«Аккаунты»** и при первом запуске создайте хранилище аккаунтов.
2. Укажите HTTPS-адрес своего совместимого сервера. На следующем шаге проверьте и подтвердите адреса API/аудиосервиса и идентичность сервера.
3. Выберите **«Вход по ID и паролю»** и введите данные существующего аккаунта.
4. Дождитесь подключения и синхронизации. Обязательного файла восстановления
   для обычного входа нет; его всё равно следует хранить для восстановления доступа.

Ввод чужого ID, неправильного пароля или недоступный сервер не создаёт другой аккаунт.
Синхронизация данных аккаунта не означает автоматическое копирование всех аудиофайлов.

На Android доступны добавление телефона через QR и восстановление с файлом или кодом.
Не создавайте новый аккаунт вместо потерянного: одинаковое отображаемое имя не восстанавливает
прежнюю идентичность. [Переносимые аккаунты](PORTABLE_ACCOUNTS.md).

После первого подключения можно перенести любимые треки или выбрать исполнителей для «Моей волны». [Импорт коллекций по ссылке](EXTERNAL_MUSIC_IMPORT.md).

## Личный сервер

Архив `autplay-server-v1.0.17.docker.tar.gz` содержит CPU-образ для Linux x86-64. Сверьте SHA-256 архива с SHA-256 в описании выпуска и импортируйте его командой `docker load -i autplay-server-v1.0.17.docker.tar.gz`. Импорт добавляет образ `autplay-server:v1.0.17` в локальный Docker. Порядок настройки и миграции описан в руководстве по развёртыванию ниже. Сервер использует схему `0081_artist_onboarding`.
Для Mac нужны совместимые серверные протоколы устройства и привязки синхронизации D1/B1.
Перед обновлением сервера выполните резервное копирование и проверку восстановления.

Для еженедельного мониторинга снятых релизов запустите обработчик получения музыки. [Настройка источников MPW и разрешений](../../tools/ACQUISITION_VAULT_BRIDGE.md#music-preservation-watcher).
