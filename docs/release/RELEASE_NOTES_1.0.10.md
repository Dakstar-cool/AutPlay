# AutPlay 1.0.10 — Android и Mac Community

Один выпуск с двумя установщиками: подписанный Android APK и Mac Community DMG для Apple Silicon.
[Установка и обновление](../operations/GET_STARTED_1.0.10.md).

## Android

- Включены актуальные управление комнатами, общая очередь, подготовка треков,
  восстановление после обрыва связи и возврат к личной очереди.
- Обновлены контроль часов и коррекция воспроизведения в комнате.
- Исправлен выбор локальных рекомендаций для загруженных с сервера треков.
- Сохранены переносимые аккаунты, история, настройки и совместимость с прежними серверными
  протоколами. Для новых серверных возможностей нужен совместимый сервер.
- Версия `1.0.10`, код `28`, пакет `app.autplay`; используется существующий ключ выпуска.

## Mac Community

- Локальная библиотека: импорт файлов и папок, поиск, плейлисты, очередь и история.
- Нативный плеер, shuffle/repeat и восстановление сохранённой позиции.
- Вход в существующий аккаунт по ID и паролю без обязательного файла восстановления.
- Синхронизация через совместимый личный сервер, отдельные адаптеры Keychain и собственная
  подпись приложения и компонентов.
- Apple Silicon, целевая macOS 13+. Сборки для Intel нет.

Community — тестовый канал. Пакет не нотарифицирован Apple и не использует Secure Enclave.
Первый запуск может требовать отдельного разрешения Gatekeeper, обновление — повторного
разрешения Keychain. Слышимый звук, полный набор кодеков, медиаклавиши и сон/пробуждение
ещё требуют ручной приёмки. Рекомендации, «Моя волна», комнаты и социальные функции
не заявлены для Mac.

## Репозиторий и безопасность

- Объединены текущий macOS-клиент, совместимый сервер D1/B1 и опубликованные Android-исправления.
- Приняты обновления GitHub Actions из PR #16, #17 и #18 с проверенными полными SHA.
- Обновлены уязвимые зависимости Brotli, brotlicffi, certifi, filelock, pyasn1 и setuptools.
  [Подробности аудита](SECURITY_FIXES_20261116.md).
- README сохраняет прежний визуальный стиль и теперь содержит установку для обеих платформ.

Контрольные суммы, исходный commit и результаты проверок конкретных файлов публикуются
рядом с установщиками в `release-manifest.json` и `SHA256SUMS`.
Выпуск клиентов не выполняет развёртывание или миграцию рабочего сервера.
