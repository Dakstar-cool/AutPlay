## Android и сервер Sona

- Со страницы исполнителя можно добавить доступные записи дискографии в серверный Vault. Записи с пометками кавера или концертной версии исключаются. У записей без таких пометок результат зависит от точности исходных метаданных.
- Поиск и группировка распознают варианты имени «25/17», в том числе «25 17» и «25-17», и учитывают участников совместных записей.
- Для треков без ReplayGain сервер измеряет воспринимаемую громкость. Android применяет поправку при воспроизведении после синхронизации метаданных.
- Обновлены обложки в медиатеке и оформление страниц исполнителей. В плеере центр указателя позиции выровнен по шкале времени.

## Установка

Android APK имеет код версии 38 и устанавливается поверх подписанной версии 1.0.14. Для Mac с Apple Silicon доступна Community-сборка. Для сервера Sona на Linux x86-64 скачайте отдельный архив Docker. Текущая ревизия серверной базы данных — `0078_playlist_snapshots`.

[Инструкция по установке и обновлению](https://github.com/Dakstar-cool/AutPlay/blob/v1.0.15/docs/operations/GET_STARTED_1.0.15.md)
