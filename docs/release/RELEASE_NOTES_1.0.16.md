# AutPlay 1.0.16

## Воспроизведение на Android

- «Моя волна» запрашивает продолжение у конца очереди. Исправлена обработка запоздавших ответов и перехода к следующей записи.
- Исправлен лишний символ между именем исполнителя и числом треков в библиотеке, а также в сведениях о загрузке.
- В панели уведомлений для оценок используются те же сердечки, что и в плеере. Приложение передаёт системе сначала «Нравится», затем «Не нравится».
- Обновлены главная, карточки исполнителей и просмотр доступных релизов. «Новинки для вас» учитывают знакомых слушателю исполнителей.

## Каталог и сохранение музыки

- При сопоставлении названий учитываются обозначения площадок, концертных сессий и видеоклипов. Уточнены выбор обложек и атрибуция исполнителей.
- Добавлен Music Preservation Watcher. Обработчик периодически проверяет отслеживаемые релизы. Для получения найденной записи нужны разрешённый источник и подтверждение её соответствия.
- Серверная схема обновлена до `0079_music_preservation`.

## Установка

Android использует пакет `app.autplay` и код версии `39`. Mac Community предназначен для Apple Silicon. Серверный образ Sona предназначен для Linux x86-64.
