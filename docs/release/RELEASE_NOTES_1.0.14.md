## Android

Откройте каталог исполнителя, просмотрите его записи и издания, сохраните треки для воспроизведения без сети. Просмотренный список треков издания доступен офлайн. Плейлистами можно обмениваться через файл `.autplaylist` или постоянную ссылку с сервера, с предпросмотром и сохранением порядка треков.

## Mac Community

В библиотеке появились страницы исполнителей и альбомов. «Моя волна» продолжает воспроизведение по локальной коллекции. С подключённым аккаунтом доступны пакеты рекомендаций, поиск с воспроизведением и сохраняемые между запусками загрузки. Плейлисты можно передавать между Android и Mac.

## Установка и обновление

- **Android 8.0+** — APK с кодом версии 37. Установите поверх подписанной версии 1.0.13, сохранив медиатеку и настройки.
- **Mac с Apple Silicon и macOS 13+** — перенесите приложение из DMG в «Программы». Community-сборка использует сертификат проекта и распространяется без нотарификации Apple.
- **Sona для Linux x86-64** — для новых серверных функций обновите образ и примените миграции до `0078_playlist_snapshots`. Перед миграцией сохраните резервную копию.
