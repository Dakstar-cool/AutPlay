# AutPlay 1.0.8

13 октября 2026 года · Android 8.0+ · build 21

Плеер для собственной музыкальной коллекции: локальные треки, переносимый аккаунт
и статистика прослушиваний. Личный сервер подключается по желанию.

## Что нового

- **Переносимый аккаунт.** Создание по ID и паролю прямо на телефоне; идентичность аккаунта
  сохраняется при подключении и смене совместимых серверов.
- **Несколько устройств.** Вход через совместимый сервер, добавление другого телефона
  через QR, синхронизация истории, предпочтений и плейлистов.
- **Статистика аккаунта.** Общие прослушивания после синхронизации; локальная статистика
  остаётся доступной при недоступном серверном API.
- **Защита и восстановление.** Выход с проверкой ID и пароля, восстановление доступа
  через заранее сохранённый файл или код.
- **Обновлённый плеер.** Управление из уведомления, свайпы по обложке, сохранение очереди
  и позиции, настройки оформления и обработка загрузки аудио.

Опция переходов между треками пропускает последние три секунды текущего и первые три секунды
следующего трека обычной очереди. Короткие и неперематываемые треки воспроизводятся целиком.

## Скачать и установить

Во вложениях выпуска — только подписанный **`autplay-1.0.8-production.apk`**.

1. Скачайте APK и откройте его на телефоне.
2. Разрешите установку для браузера или файлового менеджера, если Android запросит это.
3. Откройте **«Моя музыка» → «Добавить локальный трек»** и включите воспроизведение.

Обновление подписанной 1.0.6/build 19 до 1.0.8/build 21 проверено на Samsung M52
с сохранением данных, привязки, библиотеки и состояния воспроизведения.
При несовпадении подписи старой сборки сначала сохраните важные локальные данные.

## Личный сервер

Сервер добавляет Vault, потоковое воспроизведение, загрузку музыки и синхронизацию устройств.
Он работает на CPU. Для самостоятельного развёртывания используйте исходники репозитория,
[инструкцию развёртывания](../operations/DEPLOYMENT.md) и
[настройку переносимых аккаунтов](../operations/PORTABLE_ACCOUNTS.md).
Сервер разворачивается отдельно; во вложениях этого выпуска распространяется Android APK.

<details>
<summary>Идентичность проверенного совместимого сервера</summary>

Существующее развёртывание проверено с CPU-образом `linux/amd64` версии 1.0.7:

- Исходный commit: `f9190f0542cdab9ddd99c4bcb575dc5ad2a3eb94`.
- Alembic head: `0066_portable_local_account`.
- Docker config digest: `sha256:630d800c8f4aa5beaccd54029c55031274f8bdaaae577fc0929a17f350bb5d7e`.

Обновление Android до 1.0.8 не требует пересборки этого совместимого сервера.
Настройка нового сервера требует отдельной проверки конфигурации, HTTPS и резервных копий.

</details>

Для входа на новом устройстве нужна серверная копия аккаунта либо файл восстановления.
Синхронизация аккаунта переносит данные о музыке; аудиофайлы передаются отдельно.
Восстановление доступа не возвращает файлы, которые никогда не покидали потерянный телефон.
