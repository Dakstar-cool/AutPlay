# AutPlay 1.0.11

## Android

- «Моя волна» создаёт одну очередь. Онлайн приложение запрашивает рекомендации сервера, а без сети использует свежую подборку для текущего профиля или музыку, доступную на устройстве.
- На главной можно сразу включить «Мою волну» или добавить первый трек в пустую медиатеку. Во время воспроизведения видны обложка и управление. После паузы «Продолжить слушать» открывает плеер и возобновляет ту же очередь.
- Запоздалое событие плеера из предыдущей очереди больше не прерывает воспроизведение после переключения. Добавлена обработка пауз между треками с учётом задержки и заполнения кодека, ReplayGain и эквалайзера.
- Обновлены раздел релизов на главной, жест сворачивания плеера и навигация по настройкам. В библиотеке и мини-плеере отмеченные треки сохраняют заполненное сердце.
- Статистика пропусков каверов, ремиксов и концертных версий доступна при подключении к совместимому серверу, действующем согласии аккаунта и открытом периоде сбора.
- Пакет `app.autplay`, версия `1.0.11`, код `29`. База Room обновляется с версии 18 до 19.

## Mac Community

Сборка для Apple Silicon с обновлённым общим кодом переносимых аккаунтов. Для нового пароля нужно от 7 до 128 символов, включая знак пунктуации или другой специальный символ. Существующие парольные фразы продолжают работать. Пакет подписан сертификатом проекта. При первом открытии macOS может запросить разрешение Gatekeeper.

## Сервер Sona 0075

Администратор может задать период сбора статистики пропусков вариаций записи. Сервер учитывает согласие пользователя и отдаёт статистику его аккаунта. Для самостоятельной установки в выпуск входит архив CPU-образа Docker для Linux x86-64. Миграция `0075_sona_collection_window` создаёт первый период сбора. Администраторы могут перенести существующие даты через настройки миграции.
