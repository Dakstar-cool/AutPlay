# Исправления после полного аудита — 16 сентября 2026

Исправлены **F01–F08** из [исходного аудита](FULL_FUNCTION_AUDIT_2026-09-16.md) и три дополнительные ошибки F09–F11, выявленные повторной проверкой. На M52 установлена **0.3.4-m52, versionCode 7**. Старое состояние серверного журнала требует отдельного восстановления — подробности ниже.

## Изменения

| Дефект | Исправление и проверка |
|---|---|

| F02 — пустой поиск | Все пути записи метаданных обновляют поисковую проекцию в одной транзакции. Миграция Room 15 → 16 восстанавливает существующий индекс с сохранением алиасов. На M52 после миграции 57 поисковых записей; Ambient находит нужный трек. |
| F03 — нельзя снять лайк | Кнопки понравившихся треков доступны в библиотеке и карточке. Compose-тесты проверяют оба направления переключения. |
| F04 — переходы Repeat/Shuffle | Полный плеер использует соседей из Media3, а не границы линейного списка. Добавлена проверка доступности кнопок. |
| F05 — теряется исключение из вкусового профиля | Оценка рекомендации сохраняет существующее исключение в той же транзакции и в журнале синхронизации. Проверены Like, Dislike, Neutral и откат при ошибке. |
| F06 — невидимые ошибки команд | Общий snackbar доступен на основных маршрутах, включая плеер и загрузки. Состояние привязано к профилю; навигация убирает старое сообщение, сохраняя новое при совпадении по времени. |
| F07 — ложное обещание доступного аудио | Серверная ссылка отображается как возможный источник. Карточка сообщает, что наличие аудио проверится при воспроизведении. |

| F10 — ручной повтор ждёт старый backoff | Обнаружено на M52: кнопка повторной синхронизации добавляла работу за старым таймером примерно на три часа. Она теперь заменяет ожидающую работу, сохраняя ограничения сети и журнал. Завершение учитывает как PENDING, так и SENDING, чтобы отменяемая попытка не оставила изменения без следующего запуска. |
| F11 — устаревший статус синхронизации | Статус теперь подписан на изменения курсора и результата выполнения; дата, состояние и ошибка обновляются на открытом экране. |

## Границы проверки

Автоматизированные Android-сценарии изменяют только данные одноразового эмулятора API 26. На M52 инструментальные тесты не запускаются; лайки пользователя не переключаются. При проверке поиска выполнена короткая попытка воспроизведения найденного трека, затем плеер остановлен на паузе; исходные записи истории сохраняются.

Исправление F07 не создаёт отсутствующее аудио на сервере. Проверки реального серверного потока, Bluetooth, длительного фонового воспроизведения и нескольких физических устройств остаются отдельными сценариями исходного аудита.

Серверный код не менялся; полный серверный прогон 919 passed / 1 skipped относится к исходному аудиту. Текущая клиентская сборка дополнительно проверяется сквозными Android → HTTP → PostgreSQL сценариями.

## Остаточное состояние сервера M52

Сервер отклоняет старую привязку журнала устройства: `JOURNAL_RESET_REQUIRED`, текущий запрос синхронизации получает HTTP 409. **До обновления уже было 26 таких отклонённых событий**; новая проверка воспроизведения добавила ещё одно с тем же ответом. Авторитетный снимок метаданных при этом успешно получен.

Для полной синхронизации действий нужно восстановить соответствие устройства и эпохи журнала на сервере, сохранив исходные события и их идентификаторы. Автоматический повтор не исправляет несовпадение привязки. [Обезличенная сверка до/после](evidence/audit-fixes-2026-09-16/SERVER_JOURNAL_STATUS.json).

Изменения находятся в рабочей ветке `codex/m52-ui`; коммит и публикация в удалённый репозиторий не выполнялись.
