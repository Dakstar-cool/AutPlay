# AutPlay 1.0.8: проверка исправлений CI

Тег `v1.0.8-rc.1` используется для повторной проверки сборки релизного пакета
после исправления CI. Это техническая проверка уже опубликованной версии;
новый GitHub Release и новый подписанный APK не создаются.

## Исправления

- Android-тест выбора трека прокручивает карточку полностью перед нажатием.
  На компактном экране нажатие по частично видимой карточке попадало в нижнюю
  навигацию. Проверки точного состава очереди и сохранения экрана библиотеки остаются.
- Для `cuda-toolkit==13.0.3.0`, чей wheel не содержит сведений о лицензии,
  аудит записывает [условия NVIDIA для CUDA 13.0.3](https://docs.nvidia.com/cuda/archive/13.0.3/eula/index.html)
  и SHA-256 закреплённого wheel. Обязательная проверка условий перед публикацией
  GPU-компонентов сохраняется; неизвестные версии по-прежнему останавливают аудит.

Артефакты workflow имеют статус `UNSIGNED_CANDIDATE_NOT_FOR_PUBLICATION`.
Для установки используйте подписанный APK из [AutPlay 1.0.8](https://github.com/Dakstar-cool/AutPlay/releases/tag/v1.0.8).
