# AutPlay 1.0.17

## Музыка из других сервисов

- На Android и Mac появился импорт коллекций по ссылке из Яндекс Музыки, Spotify и SoundCloud. На Android ссылку можно отправить в AutPlay через системное меню «Поделиться».
- Предпросмотр показывает позиции в исходном порядке, повторы, пропуски и записи, доступные владельцу. Можно подтвердить неполный список, продолжить прерванный импорт или разобрать неоднозначные совпадения. Перенос избранного требует отдельного подтверждения.
- Для SoundCloud можно выбрать записи, уже доступные в каталоге AutPlay. Для Spotify доступность зависит от коллекции и полномочий подключения. Настройки по каждому источнику описаны в [руководстве по импорту](../operations/EXTERNAL_MUSIC_IMPORT.md).

## Исполнители, альбомы и Моя волна

- При первом подключении нового аккаунта на Android и Mac можно перенести любимые треки, выбрать исполнителей и раскрыть похожих. Оба шага можно пропустить. Выбор сохраняется на сервере и помогает составить первую волну.
- Рекомендации точнее учитывают группы, устойчивые дуэты и приглашённых исполнителей. Повторный импорт избранного сохраняет вес исходной оценки.
- Android и Mac показывают состав конкретного издания, диски и порядок дорожек. Приоритет у полного трек-листа MusicBrainz. При необходимости можно выбрать издание Discogs. Карточка различает подтверждённую доступность аудио в Vault, отсутствие и неизвестный статус.
- Поиск и группировка учитывают совместные записи, варианты написания и пометки Sped Up, Slowed, Nightcore и Instrumental. При подборе обложек учитываются версия трека и состав исполнителей. Уточнён отбор студийных записей и совместных треков при загрузке дискографии.

## Плеер, библиотека и загрузки

- На Android трек можно перематывать с главной. Изменены элементы управления библиотекой, расположение действий в карточках и порядок кнопок оценки в медиауведомлении.
- Загрузки треков, альбомов и плейлистов показывают ход операции. Для трека виден объём передачи, для коллекции — число сохранённых записей. Можно повторить частично завершённую загрузку. Сохранённые записи отмечены в плеере и медиатеке.
- На Mac подключение аккаунта проходит через три явных шага — адрес, подтверждение сервера и вход в аккаунт. Для проблем с идентичностью, совместимостью и доступностью сервера появились отдельные сообщения.
- Настройки Mac разделены на экраны аккаунта, оформления, музыки и загрузок, а также приложения. Можно перейти к нужной группе и вернуться к списку.

## Сервер Sona

- Добавлены API импорта коллекций и выбора исполнителей. Миграции `0080_external_collections` и `0081_artist_onboarding` сохраняют состояние импорта и начальный выбор аккаунта.
- Для поиска Discogs по исполнителю и названию альбома добавлена опциональная конфигурация Compose для API и mobile-api. [Настройка поиска](../operations/METADATA_WORKER.md#album-tracklist-lookup)
- Доступ к записи в трек-листе проверяется для текущего владельца. При повторной синхронизации сервер восстанавливает сведения, необходимые для воспроизведения доступных записей.
- В Web Admin владелец может запустить фоновое обновление отображаемых названий Vault. Изменения попадают на устройства через обычную синхронизацию.
- Обработка загружаемых файлов точнее определяет тишину на краях, учитывает тихие вступления и затухания, сохраняет паузы внутри трека и обложки Ogg. Аудиопакеты копируются без перекодирования.

## Установка и обновление

Android 8.0+, пакет `app.autplay`, код версии `40`. Mac Community рассчитан на Apple Silicon и macOS 13+. Для самостоятельного сервера предусмотрен отдельный Docker-образ Sona для Linux x86-64. Перед обновлением сервера сделайте резервную копию. Обновите API и CPU worker вместе и примените обе миграции.
