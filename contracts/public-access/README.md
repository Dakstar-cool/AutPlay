# Public access contracts

`v1/` contains the PA1 invite-only account-creation contract. Every artifact is
`IMPLEMENTED_PA2` after local PostgreSQL, CPU API/worker, and Android evidence. These credentials are distinct from M5
existing-account enrollment and S1 guest documents.

The account invitation is a secret non-HTTP app document. Never place it in a path, query, fragment,
clipboard, log, diagnostic, screenshot or export.
