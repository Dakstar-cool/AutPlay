## Начать слушать

1. [Скачайте APK 1.0.5](https://github.com/Dakstar-cool/AutPlay/releases/download/v1.0.5-m52-test.1/autplay-1.0.5-m52-test.1.apk) и установите его на Android.
2. Откройте **«Моя музыка»**, нажмите **«Добавить локальный трек»** и выберите аудиофайл.
3. Запустите воспроизведение. Сервер и аккаунт для этого не нужны.

Если у вас уже установлено основное приложение из выпуска 0.4.0, Android может отклонить
обновление: APK 1.0.5 подписан другим ключом. **Не удаляйте старое приложение, если важны
его локальная библиотека, загрузки или настройки:** удаление стирает данные приложения.

Контрольная сумма APK и подробности выпуска находятся на
[странице 1.0.5](https://github.com/Dakstar-cool/AutPlay/releases/tag/v1.0.5-m52-test.1).

## Что умеет AutPlay

- **Музыка без сети:** локальные треки, поиск, альбомы, исполнители, плейлисты и очередь.
- **Удобное продолжение:** позиция воспроизведения и очередь сохраняются после перезапуска.
- **Свои файлы:** выбирайте музыку системным диалогом Android; при подключённом сервере
  отправляйте её в личное хранилище Vault или скачивайте оттуда на телефон.
- **Карточки треков:** теги и обложки дополняют сведения о музыке; ручные правки сохраняются.
- **Визуализация Resonance Lens:** реагирует на воспроизводимое аудио и поддерживает
  уменьшение движения.
- **Личный сервер по желанию:** синхронизация, Vault, рекомендации и совместное
  прослушивание Wave. Локальная музыка остаётся доступной, когда сервер выключен.

В 1.0.5 изменена фоновая обработка недостающих обложек: работа распределяется между
несколькими очередями. Состав выпуска описан в [релизе](https://github.com/Dakstar-cool/AutPlay/releases/tag/v1.0.5-m52-test.1).

## Личный сервер

Для домашнего сервера доступен отдельный
[комплект 0.4.0](https://github.com/Dakstar-cool/AutPlay/releases/tag/v0.4.0):
установщик для Linux-контейнеров `amd64` и приложение **AutPlay LAN** для подключения
в доверенной домашней сети. AutPlay LAN устанавливается отдельно от основного приложения
и хранит собственные данные. Серверный установщик не входит в выпуск Android 1.0.5.

После установки сервера можно подключить телефон, управлять устройствами через Web Admin,
хранить музыку в Vault и синхронизировать библиотеку.
[Пошаговая установка и подключение](docs/operations/INSTALL_AND_PAIR.md) описывает
требования, настройку и ограничения домашнего комплекта.

### Загрузка музыки из TXT-плейлиста

В репозитории есть [отдельный загрузчик](tools/local_music_acquisition/README.md), который
обрабатывает TXT-список локально или как очередь на личном сервере. Доступность треков
зависит от выбранного источника; некоторые источники требуют вашей авторизации.
Используйте загрузчик только для музыки, которую вам разрешено скачивать. Обход DRM не поддерживается.

## Для разработчиков

AutPlay состоит из Android-приложения, необязательного CPU-сервера и отдельных инструментов.
На Android локальные данные хранятся в Room, воспроизведением управляет Media3,
а отложенную работу выполняет WorkManager. Сервер использует PostgreSQL для метаданных
и файловое хранилище для аудио. GPU-компоненты не нужны для основных функций.

- `apps/android` — Android UI, локальная библиотека, плеер и синхронизация.
- `server/src/autplay` — API, Web Admin, Vault, рекомендации и Wave.
- `contracts` — API и схемы обмена.
- `deploy` — Docker Compose и установщик сервера.
- `tools/local_music_acquisition` — загрузчик и сохраняемая очередь.
- `gpu` — необязательная обработка и обучение.

Версии инструментов закреплены в lock-файлах и Gradle Wrapper. Для полной настройки нужны
Python с `uv`, JDK 17, Android SDK и Docker для серверных проверок.
[Полное руководство по окружению](docs/operations/FULL_PROJECT_SETUP.md) содержит точные версии.

**Полная проверка из корня репозитория:**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\check.ps1
```

```bash
bash scripts/bootstrap.sh
bash scripts/check.sh
```

Для серверных тестов нужен временный PostgreSQL. Дополнительные зависимости, в том числе
FFmpeg и Playwright Firefox для проверок загрузчика, перечислены в руководстве по окружению.
